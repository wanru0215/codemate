# CodeMate: AI-Powered Python Learning Platform

This is an AI-assisted platform designed to help students learn Python with less anxiety. By integrating the **Gemini API**, CodeMate provides personalized guidance and real-time support to bridge the gap between beginners and coding logic.

### Key Features
- **AI Tutoring**: Interactive assistance using Google's Gemini API.
- **Student-Centric Design**: Focused on reducing learning anxiety for novice programmers.
- **Modern Tech Stack**: Built with **Node.js**, **React**, and **MongoDB**.
